# 🔐 Password Generator

A modern password generator built using Flask, HTML, CSS, and JavaScript.

## Features
- Generate secure passwords
- Copy password button
- Modern responsive UI
- Random strong password generation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Clone repository

git clone https://github.com/swathi863/password-generator.git

2. Install Flask

pip install flask

3. Run app

python app.py

4. Open browser

http://127.0.0.1:5000
